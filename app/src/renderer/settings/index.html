Conexión

VozFlow usa el plan gratuito de Groq para transcribir y limpiar tu voz. Tu API key se guarda cifrada en esta computadora.

Cómo conseguirla

  1. Entra a console.groq.com/keys e inicia sesión. No pide tarjeta.
  2. Crea una key nueva y cópiala. Solo se muestra una vez.
  3. Pégala arriba y presiona Guardar.
  4. Recomendado: en Settings, sección Data Controls, activa Zero Data Retention para que Groq no guarde nada.

    Cómo funciona

    Mantener
    Graba mientras tienes las teclas presionadas. Al soltar, limpia y pega.
    Toque rápido
    Activa manos libres. Vuelve a tocar el atajo para terminar.
    Shift
    Agrégalo en cualquier momento de la grabación para convertirla en prompt.
    Esc
    Cancela la grabación sin pegar nada.

    Si eliges Ctrl + Alt y tu teclado está en español, ten en cuenta que AltGr (para escribir @) también lo activa.
